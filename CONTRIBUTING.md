# Contributing

Open an issue describing reproducible behavior before large changes. Never submit tokens, account data, private paths, or unredacted Codex logs. Add deterministic tests for changes to parsing, classification, repair planning, or rollback. Run `Invoke-Pester ./tests -PassThru` and review `docs/security-model.md` before a pull request. Public contributions are accepted under the MIT license in this repository. Do not run privileged network or registry changes in tests.
